# End-to-End DevOps Automation

This project demonstrates a complete DevOps automation pipeline using Terraform and Ansible with GitHub Actions CI/CD.

## 🚀 CI/CD Pipeline

GitHub Actions automatically deploys infrastructure and application on every push to master branch.

## 📋 Prerequisites

- AWS Account
- GitHub Account
- SSH Key pair for EC2 access

## 🛠️ Technologies

- Terraform (Infrastructure as Code)
- Ansible (Configuration Management)
- AWS (EC2, VPC, Security Groups)
- GitHub Actions (CI/CD)
